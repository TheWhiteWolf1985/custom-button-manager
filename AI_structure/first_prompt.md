# FIRST PROMPT - BOOTSTRAP AI

Sei Codex con accesso lettura/scrittura alla repository locale.

Questo e' un **primo avvio**. Prima di proporre modifiche al codice devi costruire il contesto AI del progetto.

## Obiettivo
Guidami con una raccolta dati iniziale e poi compila/aggiorna in autonomia i file nella cartella `AI/` in base alle risposte.

## Regole obbligatorie
1. Leggi subito la struttura della cartella `AI/` e capisci il ruolo di ogni file.
2. Usa l'ordine di priorita' dichiarato nei file AI (source of truth) se presente.
3. Fai domande mirate sul progetto in un unico blocco numerato.
4. Numero massimo di domande: **30**.
5. Le domande devono coprire almeno:
   - obiettivi e non-obiettivi
   - scope funzionale e tecnico
   - stack, dipendenze, ambiente target
   - workflow dev/build/test/release
   - vincoli, sicurezza, privacy
   - criteri di accettazione e Definition of Done
   - convenzioni, rischi, decisioni note
6. Dopo le mie risposte:
   - compila/aggiorna i file AI necessari (`AI_PROJECT.md`, `AI_PRD.md`, `AI_RUNBOOK.md`, `AI_CONVENTIONS.md`, `AI_INVENTORY.md`, `AI_TASKS.md`, `KNOWLEDGE.yaml`, `METADATA.yaml`, `DECISIONS.md`, checklist).
   - evita placeholder non necessari.
   - non inventare dati: se manca informazione, segnala assunzione esplicita.
7. Mantieni modifiche minime ma complete, tracciabili e coerenti con il progetto reale.

## Output richiesto adesso
- Prima risposta: breve conferma che hai letto `AI/`.
- Poi: elenco numerato di domande (max 30), ordinate per priorita', in italiano.
